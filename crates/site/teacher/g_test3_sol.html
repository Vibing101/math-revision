Παραγοντοποίηση – Εξισώσεις 2ου και ανώτερου βαθμού · Γ΄ Γυμνασίου
1.Παραγοντοποίηση και μέθοδος
α) 5α(x − y) — κοινός παράγοντας
β) (2x − 5)² — ανάπτυγμα τετραγώνου (τέλειο τετράγωνο)
γ) (7x9)² − (10y²)² = (7x9 − 10y²)(7x9 + 10y²) — διαφορά τετραγώνων
2.Παραγοντοποίηση
α) (x + 1)(x + 7)
β) 3x(κ − λ) + 4(κ − λ) = (κ − λ)(3x + 4)
γ) 10(1 + x²) (το 1 + x² δεν αναλύεται)
δ) 3xy²(4y² + 2xy − x²)
ε) (3x)³ + (2y)³ = (3x + 2y)(9x² − 6xy + 4y²)
3.Παραγοντοποίηση
α) 2(x³ − 8) + 5(x − 2) = 2(x − 2)(x² + 2x + 4) + 5(x − 2) = (x − 2)(2x² + 4x + 13)
β) (2α − β)³ − 9(2α − β) = (2α − β)[(2α − β)² − 9] = (2α − β)(2α − β − 3)(2α − β + 3)
γ) (x − 5)(x + 4) − α(x − 5)² = (x − 5)(x + 4 − αx + 5α)
4.Εξισώσεις
α) x = 0, x = −9, x = 2
β) (5x − 1)(5x + 1) = 0: x = 15 ή x = −15
γ) 2x(x² + 5x + 4) = 2x(x + 1)(x + 4) = 0: x = 0, x = −1, x = −4
δ) x² − 11x + 24 = −4 ⇔ x² − 11x + 28 = 0 ⇔ (x − 4)(x − 7) = 0: x = 4 ή x = 7
ε) x² + 2x + 1 = 2x² + 2 + 4x ⇔ x² + 2x + 1 = 0 ⇔ (x + 1)² = 0: x = −1 (διπλή)
5.Είδος ριζών
α) x² − x + 20 = (x − 12)² + 794 > 0 για κάθε x: αδύνατη, δεν έχει πραγματικές ρίζες
β) (x + 3)(2x + 1) = 0: x = −3 ή x = −12, δύο άνισες (ρητές) ρίζες
6.Παράμετρος
(x − 3)(x − 4) = 0 ⇔ x = 3 ή x = 4. Άρα κ + 3 = 3 ή κ + 3 = 4: κ = 0 ή κ = 1
