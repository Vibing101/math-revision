β) Κοινός παράγοντας

2.Παραγοντοποίηση
α) Κοινός παράγοντας 5xy: 5xy(2x − y)
β) Τριώνυμο: γινόμενο 40, άθροισμα −13 → −5 και −8: (x − 5)(x − 8)
γ) Ομαδοποίηση: α(x + y) + 7(x + y) = (x + y)(α + 7)
δ) 4(16x² − 8x + 1) = 4(4x − 1)²
ε) Διαφορά κύβων: (α − 5)(α² + 5α + 25)
στ) Διαφορά τετραγώνων: (5α³)² − (10β²7)² = (5α³ − 10β²7)(5α³ + 10β²7)
ζ) 16(1 − 3y) = −16(3y − 1), άρα (3y − 1)(9x² − 16) = (3y − 1)(3x − 4)(3x + 4)
η) 5(y + 4) − (y² + y − 12) = 5(y + 4) − (y + 4)(y − 3) = (y + 4)(5 − y + 3) = (y + 4)(8 − y)
θ) −(y − 2) − 2(y − 2)(y + 2) + (y − 2)(y² + 2y + 4) = (y − 2)(−1 − 2y − 4 + y² + 2y + 4) = (y − 2)(y² − 1) = (y − 2)(y − 1)(y + 1)
3.Εξισώσεις
α) 3x − 7 = 0 ή x + 5 = 0: x = 73 ή x = −5
β) 5x² = 0 ή (x − 2)² = 0: x = 0 (διπλή) ή x = 2 (διπλή)
γ) α² − 2α − 24 = 0 ⇔ (α − 6)(α + 4) = 0: α = 6 ή α = −4
δ) 4x(x² − 4) = 4x(x − 2)(x + 2) = 0: x = 0, x = 2, x = −2
ε) (x − 2)² − (4x + 1)² = 0 ⇔ (x − 2 − 4x − 1)(x − 2 + 4x + 1) = 0 ⇔ (−3x − 3)(5x − 1) = 0: x = −1 ή x = 15
στ) x² − 3x + 10 = (x − 32)² + 314 > 0 για κάθε x: αδύνατη
ζ) 2x² + 6x + x + 3 = 2x(x + 3) + (x + 3) = (x + 3)(2x + 1) = 0: x = −3 ή x = −12
4.Πρόβλημα
(x + 3)(x + 8) = 2·9·2 = 36 ⇔ x² + 11x − 12 = 0 ⇔ (x + 12)(x − 1) = 0. Πρέπει x + 3 > 0, άρα x = 1. Διαστάσεις: 4 cm και 9 cm (εμβαδόν 36 cm² = 2·18 cm² ✓)
