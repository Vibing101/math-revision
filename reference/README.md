# Reference Library

Source material used to write the **theory and worked examples per chapter**.
Drop files straight into the matching folder (GitHub web UI: *Add file → Upload files*).

| Folder | Put here |
|---|---|
| `textbooks/` | Official student textbooks and workbooks |
| `teacher-guides/` | Teacher books / teaching methodology guides |
| `ministry-docs/` | Cyprus Ministry of Education documents: curriculum, syllabi, instructions, circulars |
| `pedagogy/adhd/` | Books and papers on teaching students with ADHD |
| `pedagogy/udl/` | Universal Design for Learning (UDL) guidelines and books |
| `other/` | Anything else supporting |

## Naming (recommended)

Use lowercase, no spaces, and say what/which grade/which language, e.g.:

- `textbooks/grade-1-gymnasio-maths-el.pdf`
- `teacher-guides/grade-1-teacher-guide-el.pdf`
- `ministry-docs/maths-curriculum-2021-el.pdf`
- `pedagogy/udl/cast-udl-guidelines-3.0-en.pdf`

If a book is split by chapter, use a subfolder per book.

## Size limits

- GitHub rejects files over **100 MB** (web upload limit is **25 MB** per file).
- For larger PDFs, split them by chapter, or push via git with Git LFS
  (`git lfs track "reference/**/*.pdf"`).

## Copyright

Only upload material you are allowed to keep in the repo. If this repository is
public, these files will be public too — consider making the repo private or
keeping copyrighted books out and adding only extracted notes.
